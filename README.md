# نظام تسجيل نقاط التايكوندو

نظام عربي ثابت للتحكيم وتسجيل النقاط، مع شاشة نتائج مباشرة، ثلاثة حكام فقط، وسجل نزالات قابل للتعديل.

## التشغيل المحلي

1. ثبّت الحزم: `npm install`
2. أنشئ `.env.local` من `.env.example` وأضف إعدادات البدء الآمنة.
3. شغّل: `npm run dev`
